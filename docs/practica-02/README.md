# Práctica 02 - Construcción de la red simulada en GNS3

En esta práctica se construyeron y configuraron dos topologías de red utilizando GNS3.

La primera topología estuvo formada por dos computadoras VPCS conectadas mediante un switch Ethernet. Se configuraron direcciones IP en ambos equipos y se realizaron pruebas de conectividad mediante ping.

La segunda topología estuvo formada por dos routers Cisco IOSv y un switch multicapa Cisco IOSvL2. Se configuraron las interfaces, direcciones IP, interfaces Loopback y el protocolo de enrutamiento OSPF.

Finalmente se verificó la conectividad entre los dispositivos, el establecimiento de vecinos OSPF y la tabla de enrutamiento.
