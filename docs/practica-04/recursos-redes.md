# Recursos de GNS3 y automatización de redes

## Investigación de recursos técnicos

### 1. ¿Qué tipo de problema podrías resolver consultando la documentación de GNS3?

Podría resolver problemas relacionados con la creación de topologías de red, configuración de dispositivos, conexiones entre routers y errores que se presenten durante la simulación.

### 2. ¿Qué diferencia existe entre la documentación de una herramienta y el repositorio de una biblioteca?

La documentación de una herramienta explica cómo instalarla, configurarla y utilizar sus funciones. En cambio, el repositorio de una biblioteca contiene su código fuente, ejemplos, versiones y reportes de errores que ayudan a comprender su funcionamiento.

### 3. ¿Qué información revisarías antes de utilizar una biblioteca de automatización?

Revisaría sus requisitos de instalación, compatibilidad con Python, dispositivos compatibles, funciones disponibles, ejemplos de uso y documentación oficial.

### 4. ¿Por qué es importante comprobar qué plataformas y funciones admite una biblioteca?

Porque no todas las bibliotecas funcionan con los mismos dispositivos o sistemas. Comprobar su compatibilidad permite evitar errores y seleccionar una herramienta adecuada para el proyecto.

### 5. ¿Cómo podrían utilizarse estos recursos en las siguientes prácticas?

Podrían utilizarse para resolver problemas de configuración en GNS3, consultar ejemplos de automatización, comprender el funcionamiento de bibliotecas como Netmiko y mejorar los programas de Python utilizados en el proyecto integrador.

## Recursos técnicos consultados

### Recurso 1: Documentación de GNS3

- **Nombre:** GNS3 Documentation.
- **URL:** https://docs.gns3.com/
- **Tema:** Simulación, creación y configuración de redes.
- **Tipo de información:** Guías, tutoriales e instrucciones para utilizar GNS3.
- **Utilidad para el proyecto integrador:** Ayuda a construir y configurar topologías de red simuladas con routers y otros dispositivos.
- **Ejemplo de uso:** Consultar cómo solucionar un problema de conexión entre dos routers dentro de una topología.

### Recurso 2: Netmiko

- **Nombre:** Repositorio de Netmiko en GitHub.
- **URL:** https://github.com/ktbyers/netmiko
- **Tema:** Automatización y administración de dispositivos de red mediante Python.
- **Tipo de información:** Código fuente, instrucciones de instalación, ejemplos y documentación de la biblioteca.
- **Utilidad para el proyecto integrador:** Permite investigar cómo automatizar tareas de administración en dispositivos de red compatibles.
- **Ejemplo de uso:** Consultar ejemplos para establecer una conexión SSH con un router compatible mediante Python.

### Recurso 3: Cisco DevNet

- **Nombre:** Cisco DevNet.
- **URL:** https://developer.cisco.com/
- **Tema:** Programabilidad, APIs y automatización de redes.
- **Tipo de información:** Documentación técnica, tutoriales, ejemplos y recursos para desarrolladores.
- **Utilidad para el proyecto integrador:** Ayuda a comprender cómo utilizar herramientas de programación para automatizar tareas de red.
- **Ejemplo de uso:** Consultar ejemplos de APIs para obtener información de dispositivos de red compatibles.
